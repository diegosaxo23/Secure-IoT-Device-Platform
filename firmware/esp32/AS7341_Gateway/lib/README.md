# AS7341 Local Libraries

The AS7341 sensor driver and Adafruit BusIO sources used by the equipment firmware are vendored here for reproducible builds. Their upstream copyright and license files are preserved.

ArduinoJson and PubSubClient remain pinned as direct upstream archive dependencies in `platformio.ini`. See the repository-level [`THIRD_PARTY_NOTICES.md`](../../../../THIRD_PARTY_NOTICES.md).
