Manufacturing sequence

  1. Select profile and serial port
  2. Press Program Device
  3. Check/download PlatformIO dependencies
  4. Erase ESP32 flash
  5. Build the selected source project
  6. Upload over USB
  7. Read FACTORY_READY + device ID
  8. Register the physical device
  9. Generate and inject bootstrap secret into NVS
  10. HMAC challenge + P-256 CSR
  11. Issue X.509 certificate and connect MQTT/mTLS
